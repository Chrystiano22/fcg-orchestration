3. DESCRICAO RESUMIDA DA ENTREGA

O projeto da Fase 3 evolui a arquitetura de microsservicos da Fase 2 para uma arquitetura mais profissional, com ponto de entrada unico, observabilidade, persistencia poliglota e cache distribuido.

Escopo implementado ate esta etapa:

- API Gateway com Kong
- rotas versionadas no repositorio de orquestracao
- validacao JWT no Gateway para rotas protegidas
- roteamento do Gateway para UsersAPI e CatalogAPI
- observabilidade com Prometheus e Grafana
- endpoint /metrics em UsersAPI
- endpoint /metrics em CatalogAPI
- dashboard inicial do Grafana
- MongoDB como banco NoSQL para avaliacoes de jogos
- Redis como cache distribuido para listagem do catalogo
- Docker Compose atualizado com a stack da Fase 3
- manifests Kubernetes atualizados com Gateway, observabilidade, MongoDB e Redis
- Notifications migrada para funcao serverless em projeto .NET separado
- infraestrutura como codigo da funcao criada com AWS SAM
- README central atualizado
- status da Fase 3 documentado
- testes automatizados de UsersAPI e CatalogAPI executados com sucesso
- Docker Compose validado com docker compose config
- manifests Kubernetes validados com kubectl kustomize
